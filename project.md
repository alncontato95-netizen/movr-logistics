# 1. O QUE É O MOVR?

**MOVR Logistics** é uma startup de tecnologia criada para simplificar a forma como empresas, transportadoras, motoristas, operações logísticas e outros profissionais do setor se conectam e trabalham.

O foco inicial será o ecossistema logístico de **Venlo, Limburg, Países Baixos**.

A longo prazo, o MOVR poderá expandir para os Países Baixos, Bélgica, Alemanha e posteriormente outros mercados europeus.

O objetivo inicial NÃO é criar um enorme sistema de logística.

O objetivo é:

> **Encontrar um problema real dentro da logística e criar a solução digital mais simples e útil possível para resolvê-lo.**

O produto deverá evoluir a partir de usuários reais, operações reais e feedback real do mercado.

# 10. FILOSOFIA DO MVP

O MVP não deve tentar resolver toda a logística europeia.

O MVP deve resolver **um problema específico muito bem**.

Antes de desenvolver uma funcionalidade importante, faça estas perguntas:

> Qual problema estamos resolvendo?

> Para quem?

> Como esse problema é resolvido atualmente?

> Por que alguém utilizaria o MOVR?

> Podemos testar essa solução com poucos usuários?

Se essas perguntas não puderem ser respondidas, interrompa o desenvolvimento e apresente a questão ao fundador.
